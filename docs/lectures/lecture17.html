Lecture 17: NFL Drive Simulation II

Recap

In Lecture 16, we used play-by-play data from the NFL to quantify the advantage of having first possession in overtime under the league’s original sudden death overtime rules (which were in place from 1974 to 2010) and the modified sudden death overtime rules (which were adopted in the 2010-11 season). In 2019, the Kansas City Chiefs proposed a further modification that would allow both teams to possess the ball, even if the first team scored a touchdown on their opening drive. A key consideration in deciding whether to adopt the rule was computing the probability that the second team scores a touchdown given that the first team scored a touchdown on their opening drive. If that probability is very low, then there is arguably little point to adopting the proposed rule.

As discussed in Lecture 16, we cannot estimate this probability by simply counting the number of times a team scores a touchdown after giving up a touchdown at the beginning of the first or third quarter in a tie game. This is because the dynamics of the proposed overtime period are quite a bit different than during regulation. To wit, under the proposed rules, if they are trailing by 6, 7, or 8 points, the second team

  1. Will never punt or kick a field goal on fourth down
  2. Must score a touchdown to extend the game
  3. Are relatively unconcerned about the clock

So, in order to estimate the probability, we will perform a Monte Carlo simulation study in which we repeatedly simulate the second drive. In each simulation replication, we will

  1. Randomly sample the starting field position for the second team
  2. Iteratively sample the outcome of each play in the drive from a pool of actually observed plays with similar starting contexts (i.e., yardline, down, and distance to the first down marker) until the drive ends

At the end of Lecture 16, we compiled a large pool of plays from regular season drives meeting the following criteria:

  1. The possessing team trailed by 6, 7, or 8 points
  2. The plays were from a drive that did not span multiple quarters
  3. The plays took place before the last two minutes of the half

We also computed the distribution of starting field position and time remaining for the second possession immediately following an opening drive touchdown.

Sampling Plays with Similar Contexts

We could continue iterating the above steps until the drive finishes. Before doing so, notice that the numbers of plays in the temporary pool tmp_pool differed based on the starting contexts. While some starting contexts are very well represented in plays, others are much more rare1 When running our simulation, we need to be careful when simulating a play with a rare starting context. Specifically, rather than sampling the outcome from plays with exactly the same starting context as our simulated play, we will instead sample the outcome from a pool of plays with similar starting contexts.

Intuitively, we might expect that the outcome of a 1st and 5 from your own 25 yard line is very similar to the outcome of a 1st and 5 run from 27 yard line. Similarly, we might expect that the distribution of outcomes for a 2nd and 14 play is not substantively different than the distribution of outcomes of a 2nd and 12. The following code block defines a function that takes starting context as an argument and randomly samples a play from the pool of observed plays with similar starting contexts.

In this function, we take the inputted down, ydstogo and yardline_100 values and create ranges tmp_down, tmp_ydstogo, and tmp_yardline_100 containing similar values. We then filter plays to identify a temporary pool of plays whose starting down, distance, and yardline fall within these ranges. We finally randomly sample a play out of the pool and save several features like the number of yards gained, whether it resulted in a touchdown or interception, and the time elapsed.

sample_play <- function(down, ydstogo,  yardline_100){
  if(down %in% c(1,2,3)){
    tmp_down <- c(down)
  } else{
    tmp_down <- c(3,4)
  }
  if(ydstogo == 10 | ydstogo == 1){
    tmp_ytg <- ydstogo
  } else if(ydstogo %in% 2:3){
    tmp_ytg <- 2:3
  } else if(ydstogo %in% 4:5){
    tmp_ytg <- 4:5
  } else if(ydstogo %in% 6:9){
    tmp_ytg <- 6:9
  } else if(ydstogo %in% 11:15){
    tmp_ytg <- 11:15
  } else if(ydstogo %in% 16:20){
    tmp_ytg <- 16:20
  } else{
    tmp_ytg <- 20:99
  }
  
  if(yardline_100 >= 90){
    # plays starting within 10 yards of your own end zone
    tmp_yardline <- 90:99
  } else if(yardline_100 > 60 & yardline_100 <= 90){
    # b/w your own 10 and 40: sample plays starting within 3 yards
    tmp_yardline <- yardline_100 + seq(from = -3, to = 3, by = 1)
  } else if(yardline_100 > 40 & yardline_100 <= 60){
    # b/w the 40's: sample plays starting within 2 yards
    tmp_yardline <- yardline_100 + seq(from = -2,to = 2, by = 1)
  } else if(yardline_100 > 3 & yardline_100 <= 40){
    # b/w opponent 40 and 3, add only 1 yard
    tmp_yardline <- yardline_100 + seq(from = -1, to = 1, by=1)
  } else{
    # b/w opponent 3 and goal, try to sample exactly
    tmp_yardline <- yardline_100
  }
  
  tmp_pool <-
    plays |>
    dplyr::filter(
      down %in% tmp_down &
        ydstogo %in% tmp_ytg &
        yardline_100 %in% tmp_yardline)
  
  next_play <- tmp_pool |> dplyr::sample_n(size = 1)
  
  
  output <- list()
  output[["game_id"]] <- next_play$game_id
  output[["down"]] <- next_play$down
  output[["ydstogo"]] <- next_play$ydstogo
  output[["yardline_100"]] <- next_play$yardline_100
  output[["play_type"]] <- next_play$play_type
  output[["complete_pass"]] <- next_play$complete_pass
  output[["penalty"]] <- next_play$penalty
  output[["pass"]] <- next_play$pass_attempt
  output[["rush"]] <- next_play$rush_attempt
  output[["touchdown"]] <- next_play$touchdown
  output[["interception"]] <- next_play$interception
  output[["fumble_lost"]] <- next_play$fumble_lost
  output[["yards"]] <- next_play$yards
  output[["time_elapsed"]] <- next_play$time_elapsed
  output[["desc"]] <- next_play$desc
  return(output)
}

Drive Simulation

The following code block defines a function to simulate an entire drive under the simulated overtime rules. In the inner loop of the function, we call sample_play() to draw the outcome of the simulated play. Then, the function works through lots of logic to determine the starting context of the next play.

simulate_drive <- function(){
  
  # First get starting position
  down <- 1
  ydstogo <- 10
  tmp_yd_time <- drive2_start |> dplyr::slice_sample(n = 1)
  yardline_100 <- tmp_yd_time$yardline_100
  time <- tmp_yd_time$quarter_seconds_remaining - 300
  
  play_counter <- 1
  continue_drive <- TRUE
  result <- NA
  
  play_info <- list()
  sampled_plays <- list()
  
  while(continue_drive){
    output <- sample_play(down = down, ydstogo = ydstogo, yardline_100 = yardline_100)
    
    sampled_plays[[play_counter]] <- output
    
    play_info[[play_counter]] <-
      data.frame(down = down, ydstogo = ydstogo, yardline_100 = yardline_100,
                 time = time,
                 play_type = output$play_type,
                 complete_pass = output$complete_pass,
                 penalty = output$penalty,
                 yards = output$yards,
                 time_elapsed = output$time_elapsed)
    if(is.na(output$yards)){
      if(output$interception == 1){
        continue_drive <- FALSE
        result <- "Interception"
      } else if(output$fumble_lost == 1){
        continue_drive <- FALSE
        result <- "Fumble Lost"
      } else if(output$touchdown == 1){
        continue_drive <- FALSE
        result <- "Touchdown"
        play_info[[play_counter]][["yards"]] <- output$yardline_100
      } else{
        continue_drive <- FALSE
      }
    } else{
      if(output$time_elapsed >= time & output$yards <= yardline_100){
        continue_drive <- FALSE
        result <- "Clock Expired"
      }
      if(output$yards >= yardline_100){
        continue_drive <- FALSE
        result <- "Touchdown"
      } else if(yardline_100 - output$yards > 99){
        continue_drive <- FALSE
        result <- "Safety"
      } else if(output$interception == 1 | output$fumble_lost == 1){
        continue_drive <- FALSE 
        result <- "Turnover"
      } else if(down == 4 & output$yards < ydstogo){
        continue_drive <- FALSE
        result <- "Downs"
      } else{
        # drive doesn't end: check whether the play results in a first down
        time <- time - output$time_elapsed
        if(output$yards >= ydstogo){
          down <- 1
          yardline_100 <- yardline_100 - output$yards
          if(yardline_100 < 1) stop("something went wrong: yardline_100 < 1!")
          ydstogo <- min(c(yardline_100, 10))
        } else{
          # team did not get a first down
          down <- down + 1
          if(down > 4) stop("something went wrong: down > 4!")
          yardline_100 <- yardline_100 - output$yards
          if(yardline_100 < 1 | yardline_100 > 99) stop("something went wrong: play resulted in TD or safety but wasn't flagged earlier")
          ydstogo <- ydstogo - output$yards
        }
      } # closes else checking whether drive ends
    } # closes if/else checking whether yards is NA
    play_counter <- play_counter + 1
  }
  
  return(
    list(result = result,
         play_info = play_info,
         sampled_plays = sampled_plays))
}

In the following code, we run the simulation 10,000 times and tabulate the different drive results.

set.seed(441)
n_sim <- 10000
results <- rep(NA, times = n_sim)
for(r in 1:n_sim){
  set.seed(441+r)
  drive <- simulate_drive()
  results[r] <- drive$result
}
table(results)/n_sim

Comparing these probabilities to those obtained by the NFL League Office, we see quite a big disparity in the probability of a touchdown. As an exercise, think about why that might be!
