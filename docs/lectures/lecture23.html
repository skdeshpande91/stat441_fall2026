Lecture 23: NBA Tracking Data

Motivation: Play Animation

In Game 5 of the 2026 NBA Finals, the New York Knicks scored their first points on a Jalen Brunson 3 point shot. Figure 1 shows an animation of the same play in which players are represented as dots (colored according to their team) move aross the plane (representing the court)

We will recreate this figure using recently-released tracking data from the NBA.

Tracking Data in the NBA

NBA teams have used cameras to collect player tracking data during games since the 2009-10 regular season. Initially, the league used SportVU, a system of six cameras and proprietary computer vision software initially developed for soccer. In 2013, the league announced a partnership with STATS, LLC to deploy SportVU in all arenas and collect & distribute the data league-wide. That partnership was renewed for the 2016-17 season before the league switched to a different vendor (Second Spectrum) for its optical tracking data. Before the 2023-24 regular season, the NBA announced a new partnership with Sony’s Hawk-Eye Innovations to deploy Hawk-Eye’s 3D optical tracking system in all arenas.

Unlike the NFL, the NBA has been extremely reluctant to release any of its tracking data to the public. Much of the public research1 based on these data has been done by groups who received special access. Despite the lack of formal data releases, some NBA tracking data has still made it to the public domain.

During the 2014-15 regular season, the NBA added a feature to its website in which fans could watch video clips of individual players’ shots and visualize the player & ball movements as dots moving around the court. Neil Johnson found the data underpinning this functionality, scraped it, and shared all that data publicly on GitHub 2. In total, he got 632 games worth of data before the data were taken offline (and the NBA removed the tracking data visualization functionality from its website)3. Since the data were publicly posted, many people have developed code for processing, analyzing, and visualizing these data. I recommend this repository from Rajiv Shah if you want to play around with the older tracking data.

For the better part of a decade, these 632 games from the 2015-16 regular season were the only publicly available NBA tracking data until recently. In October 2026, the NBA announced several new features to its app including Game Pulse which, to quote the NBA’s press release “combines live court visualization… in a live-updating experience.” In other words, the dots on the court had returned and Neil Johnson once again found the underlying data, scraped it, and posted it publicly4.

We will work with a portion of these data to create an animation of a single possession from Game 5 of the 2026 NBA Finals.

Getting Started with Tracking Data

The full data archive (which is about 5GB in size) contains several files and a large directory containing the tracking data. That directory contains sub-directories (one for each day) and each day’s directory contains sub-directories (one for each game). The games are uniquely indexed by a 10-digit numeric id. For instance, the ID for Game 5 of the 2026 Finals is 0042500405.

Each game’s directory contains several JSON files5. Player-tracking data is incredibly structured: player coordinates are nested within frames and frames are nested within games. This makes JSON particularly well-suited for storing tracking data.

The following codeblock builds a data table where each row is a frame-player combination. It will contain all available tracking data in a long format

positions <- list()
for(i in 1:nrow(tracking_data)){
  tmp_players <- 
    tracking_data$home_players[[i]] |>
    dplyr::bind_rows(tracking_data$away_players[[i]]) |>
    dplyr::rowwise() |>
    dplyr::mutate(x = unlist(xyz)[1], y = unlist(xyz)[2], z = unlist(xyz)[3]) |>
    dplyr::ungroup() |>
    dplyr::select(-xyz)
  
  if(!is.null(tracking_data$ball$xyz[[i]])){
    tmp_ball <-
      data.frame(
        player_id = 0L,
        team_id = 0L, 
        on_court = TRUE, 
        x = tracking_data$ball$xyz[[i]][1],
        y = tracking_data$ball$xyz[[i]][2],
        z = tracking_data$ball$xyz[[i]][3])
  } else{
    tmp_ball <-
      data.frame(
        player_id = 0L, 
        team_id = 0L, 
        on_court = TRUE, 
        x = NA,
        y = NA,
        z = NA)
  }
  
  
  
  positions[[i]] <-
    dplyr::bind_rows(tmp_players, tmp_ball) |>
    dplyr::mutate(
      frame = i,
      game_clock_ms = tracking_data$game_clock_ms[i],
      period = tracking_data$period[i],
      timestamp_ms = tracking_data$timestamp_ms[i],
      timestamp_utc = tracking_data$timestamp_utc[i])
  
  
}

positions_df <-
  dplyr::bind_rows(positions) |>
  dplyr::left_join(
    y = player_df |> dplyr::rename(player_id = personID) |> dplyr::select(player_id, name, jersey))

Animating a Single Play

We will focus on the first made shot by the Knicks in the game — a successful 3 point shot by Jalen Brunson. To do this end, we create a single data frame where the game clock is between 9:48 and 9:28 in the first quarter.

possession <-
  positions_df |>
  dplyr::filter(period == 1 & 
                  game_clock_ms < (9 * 60 + 48) * 1000 & 
                  game_clock_ms >= (9*60 + 28) * 1000) |>
  dplyr::arrange(frame)

Adding Court Landmakrs

We can improve the plot above by adding in several court landmarks based on measurements provided in the NBA Rulebook.

draw_circle <- function(center = c(0,0), theta_start = 0, theta_end = 2*pi, radius = 1, lwd = 1.5, lty = 1){
  theta_seq <- seq(theta_start, theta_end, length = 1000)
  x <- center[1] + radius*cos(theta_seq)
  y <- center[2] + radius*sin(theta_seq)
  lines(x,y, lwd = lwd, lty = lty)
}

Frame-by-Frame Illustration

To create an animation, we will make a separate image showing all players and the ball in each frame. Then, we can stitch those images together into a GIF. To simplify this process, we define a function in the codeblock that plots the locations in each frame.

plot_frame <- function(frame_number, homeID, awayID, home_col, away_col){
  
  plot_court()
  players <-
    possession |> 
    dplyr::filter(frame == frame_number & player_id != 0L) |>
    dplyr::mutate(
      col = dplyr::case_when(
        team_id == homeID ~ home_col,
        team_id == awayID ~ away_col))
  ball <-
    possession |>
    dplyr::filter(frame == frame_number & player_id == 0L) |>
    dplyr::mutate(col = "orange")
  
  points(players$x, players$y,
         pch = 16, cex = 3,
         col = players$col)
  text(players$x, players$y, labels = players$jersey, cex = 0.75,
       col = "white")
  mtext(frame_number, side = 3)
  
  points(ball$x, ball$y, col = ball$col, pch = 16)
}

In order to create an animation, we can plot the player and ball location in each frame and stitch them together into a GIF using ImageMagick. You will first need to download the binary associated with your system from the ImageMagick website and follow the appropriate installation instructions. Then, once you have saved the frame-by-frame images sorted chronologically by frame number in a directory, you can use the command magick to create a GIF. Full documentation for creating such animation is available here. The most salient option to run with magick is delay, which controls the length of the pause between images. Since the NBA data is sampled every 200ms, we will specify the option -delay 20 to match the 5 frames per second rate in the data.

ImportantSubdirectory for Images

In the codeblock below, I set the variable target and use it when calling png. This is the name of a sub-directory that I created within my working directory to hold the frame-by-frame images. If you want to run this code locally, you will need to create a similar sub-directory and update the assignment of target with that sub-directory’s name.

target <- "figures/lecture23/"
for(frame_number in unique(possession$frame)){
  png(paste0(target, "/brunson3pt_", frame_number, ".png"),
      width = 8, height = 4.5, units = "in", res = 400)
  plot_frame(frame_number = frame_number, homeID = homeID, awayID = awayID,
             home_col = spurs_black, away_col = knicks_blue)
  dev.off()
}
